This blog post explains Google [ADK](https://adk.dev/), an open-source, code-first framework designed to build, debug, 
evaluate, and deploy AI agents and multi-agent systems. ADK supports five programming languages:
Python, Go, TypeScript, Java, and Kotlin. In this blog, we focus on Python version of ADK.

## Python Quickstart <a name="quick_start"></a>

Prerequisites: You need Python 3.10 or newer and `pip` for installing packages.

- **Create a Python virtual environment and activate it**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

- **Install ADK**

```bash
pip install google-adk
```

- **Create a new project using `adk create` command**

```bash
adk create my_agent
```

This command creates the following files in my_agent folder:

```bash
my_agent/
    agent.py      # main agent code
    .env          # API keys or project IDs
    __init__.py
```

- **Update the agent definition:**

The `agent.py` file contains an agent definition. You can define tools for the agent to use.
Update `agent.py` code to include a `get_current_time` tool for use by the agent, as follows:

```python
from google.adk.agents.llm_agent import Agent

# Mock tool implementation
def get_current_time(city: str) -> dict:
    """Returns the current time in a specified city."""
    return {"status": "success", "city": city, "time": "10:30 AM"}

root_agent = Agent(
    model='gemini-flash-latest',
    name='current_time_agent',
    description="Tells the current time in a specified city.",
    instruction="""You are a helpful assistant that tells the current time in cities.
    Use the 'get_current_time' tool for this purpose.""",
    tools=[get_current_time],
)
```

- **Set your API key**

This agent network uses a Gemini model which requires an API key. Get an API key from
[Google AI Studio](https://aistudio.google.com/app/apikey) and write it into your `.env`
file via:

```bash
echo 'GOOGLE_API_KEY="YOUR_API_KEY"' > .env
```

- **Run your agent via command-line interface**

```bash
adk run my_agent
```
Image below shows a sample interaction with the agent.

![Agent interaction]({{ site.baseurl }}/images/my_agent_cli.png)

- **Run your agent via web interface**

The command below starts a web server with a chat interface for your agent. You can
access the web interface at http://localhost:8000. Select the agent at the upper
left corner and type a request.

```bash
adk web --port 8000
```

![Agent interaction]({{ site.baseurl }}/images/my_agent_web.png)

- **Run your agent by sending requests to an API server**

The command below will launch a local web server on http://localhost:8000

```bash
adk api_server --auto_create_session
```

The `--auto_create_session` flag automatically generates a new session if one
does not already exist when running the application. You can use `curl` commands
to interact with the local web server.

To check server's health or it's version:

```bash
curl -X GET http://localhost:8000/health
curl -X GET http://localhost:8000/version
```

To list the available agent network:

```bash
curl -X GET http://localhost:8000/list-apps
```

To send a request to `my_agent` agent network:

```bash
curl -X POST http://localhost:8000/run \
  -H "Content-Type: application/json" \
  -d '{
    "appName": "my_agent",
    "userId": "u_123",
    "sessionId": "s_abc",
    "newMessage": {
      "role": "user",
      "parts": [{"text": "Hello, can you help me?"}]
    }
  }'
```

## Building a Multi-tool Agent <a name="multi_tool"></a>

Simply, define another function in `agent.py`, e.g.:

```python
# Mock tool implementation
def get_current_weather(city: str) -> dict:
    """Returns the current weather in a specified city."""
    return {"status": "success", "city": city, "weather": "Sunny with a temperature of 77 degrees Fahrenheit"}
```

Add the new function name to `tools` list in `root_agent`, and update the description/instruction:

```python
root_agent = Agent(
    model='gemini-flash-latest',
    name='root_agent',
    description="Tells the current time or weather in a specified city.",
    instruction="""You are a helpful assistant that tells the current time or weather in cities.
    Use the 'get_current_time' or 'get_current_weather' tools for these purposes.""",
    tools=[get_current_time, get_current_weather],
)
```

## Manual Runner/Session Setup <a name="runner_session"></a>

When you run an agent network using the ADK CLI (such as `adk web`), the CLI handles a lot
of the boilerplate infrastructure under the hood -- it automatically instantiates a `SessionService`
to manage the sessions between users and agents, and a `Runner` that drives the agent's execution
loop, taking incoming user messages and invoking the necessary models or tools.

While the ADK CLI is an exceptional tool for rapid prototyping, debugging, and local development, it is
designed primarily as a developer sandbox. For production environments, we must explicitly define
a `SessionService` and a `Runner`, which we will do next.

- **Import the necessary packages**

```python
from google.adk.sessions import InMemorySessionService
from google.adk.runners import Runner
from google.genai import types # For creating message Content/Parts
```

The `InMemorySessionService` is a simple implementation of `SessionService` that stores everything in
memory, suitable for testing and simple applications.

- **Instantiate a `SessionService` object**

```python
session_service = InMemorySessionService()

# Define constants for identifying the interaction context
APP_NAME = "current_time_app"
USER_ID = "user_001"
SESSION_ID = "session_001" # Using a fixed ID for simplicity

async def init_session(app_name:str, user_id:str, session_id:str) -> Session:
    session = await session_service.create_session(
        app_name=app_name,
        user_id=user_id,
        session_id=session_id
    )
    return session

session = asyncio.run(init_session(APP_NAME, USER_ID, SESSION_ID))
```

- **Instantiate a `Runner` object**

```python
runner = Runner(
    agent=current_time_agent, # The agent we want to run
    app_name=APP_NAME,   # Associates runs with our app
    session_service=session_service # Uses our session manager
)
print(f"Runner created for agent '{runner.agent.name}'.")
```

- **Interact with the agent**

```python
async def call_agent_async(query: str, runner, user_id, session_id):
  """Sends a query to the agent and prints the final response."""

  # Prepare the user's message in ADK format
  content = types.Content(role='user', parts=[types.Part(text=query)])
  final_response_text = "Agent did not produce a final response." # Default

  # Key Concept: run_async executes the agent logic and yields Events.
  # We iterate through events to find the final answer.
  async for event in runner.run_async(user_id=user_id, session_id=session_id, new_message=content):
      # is_final_response() marks the concluding message for the turn.
      if event.is_final_response():
          if event.content and event.content.parts:
             # Assuming text response in the first part
             final_response_text = event.content.parts[0].text
          elif event.actions and event.actions.escalate: # Handle potential errors/escalations
             final_response_text = f"Agent escalated: {event.error_message or 'No specific message.'}"
          break # Stop processing events once the final response is found

# We need an async function to await our interaction helper
async def run_conversation():
    await call_agent_async("What is the time in London?", runner=runner, user_id=USER_ID,session_id=SESSION_ID)

if __name__ == "__main__":
    try:
        asyncio.run(run_conversation())
    except Exception as e:
        print(f"An error occurred: {e}")
```
